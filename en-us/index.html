Features

Built for cleaning up a whole library

Not a one-file web toy. Recursive folders, parallel jobs, tags and covers, retries and a CSV report are all included.

⇄

Four platforms

Recognises NCM, QMC, KGG / KGM, KWM and MFLAC extensions. When the extension is unknown it sniffs the file header.

▦

Recursive batches

Drop a folder and it expands every encrypted track underneath, queues them by your concurrency setting, and never silently overwrites.

♪

Tags and cover art

Writes title, artist, album and artwork into FLAC / MP3 / OGG / M4A / WAV. Kugou files fall back to the local cache, then the cover CDN.

☰

Windows 11 menu

Right-click an encrypted file and the top-level menu offers “Decrypt with MusicUnlock” — no need to open the main window first.

↻

Retry and export

Retry one job or every failed job. When a batch ends, export a CSV list of sources, outputs, states and notes.

Workflow

Three steps, then it is out of your way

1Add

Drop files or folders

Multi-select and recursive folders are supported, including a hand-off from Explorer.

2Output

Lands in your Music folder

Chinese systems use “音乐\MusicUnlock 输出”; other locales use “Music\MusicUnlock_output”. Change it any time.

3Start

Parallel, cancellable, visible

Every file has its own progress and state. Open the result in place, or export the whole batch as CSV.

Your files never leave the machine

All decryption code ships inside the desktop app. Audio, names and hashes are never uploaded. The only optional network call is the cover-art lookup, and it sends track metadata for an image — never the file.

FAQ

Read these first

Where is the context menu entry?

Right-click an encrypted file and the top-level menu shows “Decrypt with MusicUnlock”. Plain audio and unsupported extensions do not show it.

Does uninstalling the app delete my music?

No. Source files are read-only and output goes to the folder you choose. Uninstalling the app or clearing settings never touches your music.

Why is Kugou KGM v5 unsupported?

Some newer KGM files use a key derivation that is not public. The app marks them as unsupported instead of writing a truncated file. Export a plain format from the Kugou client first.

Will it overwrite existing files?

Encrypted inputs are opened read-only. If a name already exists in the output folder, the default is to add (1)(2); overwrite and skip are also available.

Which output formats are produced?

The original container is restored as MP3, FLAC, M4A, OGG or WAV. There is no lossy re-encoding.
